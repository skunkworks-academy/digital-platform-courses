## Learning quality

All tracks have defined outcomes, six modules, three labs, knowledge checks and capstone evidence. The Microsoft 365 and AI Automation tracks also include interactive five-question baseline/final diagnostics. An Academy badge requires verified enrolment and human assessment; a browser score alone does not qualify.

## Selling status

This is a **draft curriculum and UX preview**, not a commercial course delivery system. Real PayPal checkout, per-course protected access, verified learning records and automated email fulfilment are pending backend implementation and testing. Do not send this link as an automatic paid-enrolment product.
