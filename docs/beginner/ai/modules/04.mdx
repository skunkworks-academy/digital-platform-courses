# Module 4: Documents, summaries and communication

**Time:** about 45–60 minutes. **Outcome:** The output retains all essential facts and never invents task ownership, deadlines or approvals.

## Learn: core concepts

AI can condense long material, extract action items, restructure notes and suggest accessible writing. The human author must check that a summary preserves decisions, dates, owners and caveats. A safe document workflow starts with data classification: public, internal, confidential or regulated. Only approved content may be uploaded. Apply accessible structure with descriptive headings, concise sentences, alt-text drafted then reviewed and explicit next actions.

## Realistic workplace scenario

Given fictional meeting notes containing six actions, a prompt requests an action register with owner, deadline, dependency and unresolved question. Blank owner fields remain 'unassigned' rather than being fabricated.

## Guided activity

1. Create one page of fictional meeting notes with decisions, open questions and five tasks.
2. Prompt for a 120-word summary plus a four-column action register.
3. Compare each extracted fact with the source; highlight omissions or invented commitments.
4. Rewrite one stakeholder email and assess tone, accuracy and accessibility with a checklist.

## Verify your result

The output retains all essential facts and never invents task ownership, deadlines or approvals. Produce a brief validation table with columns **expected result**, **actual result**, **evidence**, **decision** and **remediation**. The observed result must match the stated purpose without accidental disclosure or unapproved action.

:::warning Responsible practice
Summaries compress; they can lose risk notes. Keep an auditable link to the original authorized document.
:::

## Self-check and feedback

1. Why should missing owners be left unassigned?
2. Which information must be checked before sending a model-drafted email?

<details>
  <summary>Read feedback after answering</summary>

The answer must demonstrate the principles taught above: verification against evidence, safe handling, defined responsibility and a reproducible process. Revisit the scenario if you cannot show how a reviewer would confirm the result independently.

</details>
