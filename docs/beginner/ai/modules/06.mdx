# Module 6: Building a safe personal AI workflow

**Time:** about 45–60 minutes. **Outcome:** The workflow names a human owner, evidence, exception path, privacy boundary and measurable improvement target.

## Learn: core concepts

A workflow includes an input, transformation, review checkpoint, output, owner and feedback loop. Start with one small task before considering automation. Create a repeatable prompt template and a quality rubric. Put mandatory human approval on consequential actions. Data minimisation, appropriate retention, consent, copyright and company policy are design inputs—not optional afterthoughts. Evaluate benefit by comparing total time before and after, including verification and rework.

## Realistic workplace scenario

A sales representative uses AI to draft three fictional customer follow-ups, manually checks every claim, then sends only messages approved in a customer relationship management process.

## Guided activity

1. Choose one low-risk repetitive task and record current handling time and error frequency for five simulated examples.
2. Design the workflow using a trigger, permissible input, prompt template, validation checklist, authorized approver and archived output.
3. Pilot three examples and calculate preparation time plus review time, not just time saved in drafting.
4. Write a stop rule for unexpected disclosure, fabricated claims or inconsistent output.

## Verify your result

The workflow names a human owner, evidence, exception path, privacy boundary and measurable improvement target. Produce a brief validation table with columns **expected result**, **actual result**, **evidence**, **decision** and **remediation**. The observed result must match the stated purpose without accidental disclosure or unapproved action.

:::warning Responsible practice
Do not confuse 'fully automated' with 'safe'. A human can approve work before any external communication or irreversible action.
:::

## Self-check and feedback

1. How is net time saving calculated?
2. Which actions should remain subject to a human approval gate?

<details>
  <summary>Read feedback after answering</summary>

The answer must demonstrate the principles taught above: verification against evidence, safe handling, defined responsibility and a reproducible process. Revisit the scenario if you cannot show how a reviewer would confirm the result independently.

</details>

## Evidence to retain

- [ ] A titled task artefact with fictional or permitted input.
- [ ] Explicit expected and observed results.
- [ ] One failure or negative test and corrective action.
- [ ] A concise reflection explaining the relevance to daily work.
