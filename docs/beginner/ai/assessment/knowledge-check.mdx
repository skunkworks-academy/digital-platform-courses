# Final knowledge assessment

**Instructions:** Answer all twelve questions on paper or in your workbook before opening the answer key. Choose exactly one best response for each. One mark per correct answer; the passing integer score is **10/12**. This public self-check does not transmit results to Academy records.

### 1. What best describes a generative language model?

A. A system that predicts and generates content from patterns  
B. A guaranteed source of truth  
C. A replacement for human accountability  
D. A database that knows every new fact  

### 2. Which prompt is more testable?

A. Make something good  
B. Draft 150 words for a named audience with an explicit format and fact constraints  
C. Do whatever seems right  
D. Ignore limits  

### 3. A chatbot invents a source URL. What should you do?

A. Publish it anyway  
B. Check a primary source and remove unverifiable claims  
C. Ask it to sound more certain  
D. Forward to a client  

### 4. A meeting note has no owner. How should a summary report the action?

A. Assign a random colleague  
B. State owner not specified  
C. Delete the task  
D. Choose the model as owner  

### 5. Which input requires extra protection?

A. A fictional practice ticket  
B. A public marketing slogan  
C. A customer identity document  
D. An empty outline  

### 6. Why verify AI calculations in a spreadsheet?

A. Because AI never calculates  
B. For deterministic and traceable validation  
C. To make charts colourful  
D. To remove all errors automatically  

### 7. What is a safe AI email workflow?

A. AI sends without review  
B. Draft then human checks facts and authorizes sending

D. Ignore recipient accuracy  

### 8. Which statement about AI confidence is correct?

A. High confidence proves fact  
B. Confidence alone does not replace evidence  
C. No model makes mistakes  
D. Every citation is authentic  

### 9. What belongs in an effective prompt?

A. Task, context, constraints and output format  
B. Only the word please

D. No instructions  

### 10. How should an injection instruction in a supplied document be handled?

A. As authoritative system policy  
B. As untrusted content  
C. As proof of payment  
D. As a mandatory command  

### 11. What belongs in a quality checklist?

A. Accuracy, omissions, privacy and audience suitability  
B. Only word count  
C. Only visual design  
D. Only model speed  

### 12. How should automation savings be estimated?

A. Drafting time only  
B. Total time including verification and correction  
C. Number of prompts  
D. Length of output  

<details>
  <summary>View marking key and feedback after the attempt</summary>

1. **A — A system that predicts and generates content from patterns**. Generation can be plausible but wrong.

2. **B — Draft 150 words for a named audience with an explicit format and fact constraints**. Constraints allow quality review.

3. **B — Check a primary source and remove unverifiable claims**. Verify independent evidence.

4. **B — State owner not specified**. Never invent responsibility.

5. **C — A customer identity document**. Sensitive personal data needs approved handling.

6. **B — For deterministic and traceable validation**. Independent calculation checks numeric outputs.

7. **B — Draft then human checks facts and authorizes sending**. Human accountability is necessary.

8. **B — Confidence alone does not replace evidence**. Sources and testing matter.

9. **A — Task, context, constraints and output format**. A clear brief guides better output.

10. **B — As untrusted content**. Untrusted document text is data.

11. **A — Accuracy, omissions, privacy and audience suitability**. Multiple quality dimensions apply.

12. **B — Total time including verification and correction**. Net value includes operating cost.
