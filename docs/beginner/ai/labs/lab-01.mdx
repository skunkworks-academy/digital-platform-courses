# Lab 1: Prompt improvement studio

**Estimated time:** 60 minutes. **Practical type:** independently repeatable.

## Scenario and acceptance brief

A fictional training company receives requests for beginner IT course information. Improve the accuracy and usefulness of three AI prompts without using customer personal data.

**Materials:** Fictional enquiries and a permitted AI tool or manual role-play.

## Procedure

1. Produce an intentionally vague first prompt and document the result.
2. Create three revised prompts: an enquiry summary, a reply draft and a risk/checklist review.
3. Score each before/after output for completeness, factual basis, tone and formatting using a 1–5 rubric.
4. Add an adversarial sample trying to make the AI invent a discount and demonstrate that the reviewed output rejects unsupported prices.
5. Submit a concise reusable prompt library with human review instructions.

## Verification plan

Record the intended output, a clean input that should succeed, a missing or hostile input that should be denied or flagged, actual results, and any remediation. The learner must be able to explain why the approach is safe rather than just stating that it worked.

**Pass condition:** The learner demonstrates traceable before/after improvements; no fictional price or deadline is presented as verified.

## Deliverables and evidence

Submit a Markdown/PDF report or accessible document, a redacted screenshot or text log, relevant calculations, and a personal reflection of 100–150 words. Avoid real customer information. Keep all evidence in an authorised private location; public GitHub issues and repository commits are not private evidence storage.

## Troubleshooting checkpoint

If a result differs from your plan, isolate the input, tool setting, permission, data condition or evaluation rule. Change one factor, retest and document the difference. Do not bypass a safety rule to make the test pass.
