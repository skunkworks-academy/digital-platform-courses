# Knowledge assessment

Answer all twelve questions independently and only then view the key. One point per correct answer. Minimum knowledge pass: **10/12** (meets 80%). This public assessment is a self-check and does not automatically create an Academy record.

<details>
  <summary>Open answer key and rationale</summary>

1. **A — A ready-to-use application service**. SaaS abstracts much application management.

2. **A — Virtual compute, network and storage resources**. IaaS exposes infrastructure resources.

3. **A — Ability to adapt resource capacity to changing demand**. Elasticity adjusts capacity.

4. **A — Separated infrastructure within a supported region**. Zones help isolate some infrastructure failures.

5. **A — Object storage**. Object storage uses objects/buckets or analogous constructs.

6. **A — Appropriate data access and configuration**. Responsibility depends on service model.

7. **A — Only required permissions for the job**. Scope authorisation to necessity.

8. **A — Running compute continuously and data egress**. Usage charges vary by service.

9. **A — Check limits, budget and billing ownership**. Free tiers still require governance.

10. **A — Target time to restore service**. RTO is recovery-time objective.

11. **A — Acceptable potential data loss in time**. RPO is recovery-point objective.

12. **A — Health/recovery validation and stakeholder acceptance**. Verified results and owner sign-off matter.

</details>

For missed responsibility and architecture items, repeat Modules 1–4. For pricing or recovery, repeat Modules 5–6. Passing knowledge alone does not replace safe practical evidence and capstone moderation.
