# Final knowledge assessment

Take the twelve-question test without opening the answer key. Choose one answer to each and record choices A–D. One point each; **10/12** is the minimum passing score. This public exam is for practice and does not create a verified academic record.

### 1. What is a common characteristic of cloud computing?

- **A.** On-demand provisioned services
- **B.** Guaranteed no outages
- **C.** No customer responsibilities
- **D.** All workloads are free

### 2. Which model most directly delivers a ready-to-use application?

- **A.** SaaS
- **B.** IaaS
- **C.** Raw metal purchase
- **D.** A home router

### 3. In IaaS, who is commonly responsible for patching the guest OS?

- **A.** The customer
- **B.** No one
- **C.** The student
- **D.** A domain registrar

### 4. What is a cloud region?

- **A.** A geographic deployment area
- **B.** A password strength level
- **C.** A spreadsheet format
- **D.** An API key

### 5. Which storage is typically suited to images and documents as objects?

- **A.** Object storage
- **B.** CPU registers
- **C.** GPU cache
- **D.** Printer RAM

### 6. Why should a learner database not be directly internet-accessible?

- **A.** To reduce unauthorised access surface
- **B.** To increase its public search ranking
- **C.** To avoid all logging
- **D.** To allow anonymous updates

### 7. Which practice improves account security?

- **A.** Unique accounts, MFA and least privilege
- **B.** Shared master credentials
- **C.** Public API tokens
- **D.** Anonymous admin

### 8. What does RPO describe?

- **A.** Maximum acceptable data-loss interval
- **B.** Target screen brightness
- **C.** Monthly cloud budget
- **D.** Number of staff meetings

### 9. Why must restores be tested?

- **A.** To prove recovery works in practice
- **B.** To reduce chart size
- **C.** Because a backup always means instant recovery
- **D.** To remove encryption

### 10. Which category can unexpectedly increase a cloud bill?

- **A.** Outbound network data transfer
- **B.** Only logo design
- **C.** Only the DNS name
- **D.** Only keyboard layout

### 11. What should occur before a production deployment?

- **A.** Review, test, monitor and plan rollback
- **B.** Disable access controls
- **C.** Commit secrets to Git
- **D.** Delete logs

### 12. What is the best root-cause approach after an error?

- **A.** Correlate impact, logs, metrics and recent changes
- **B.** Assume the provider is always at fault
- **C.** Reinstall every machine
- **D.** Ignore customer symptoms

<details>
  <summary>Open the answer key and explanations when finished</summary>

1. **A — On-demand provisioned services**. Cloud commonly uses on-demand and measured services.

2. **A — SaaS**. SaaS provides an application as a service.

3. **A — The customer**. Guest OS management typically remains with the customer.

4. **A — A geographic deployment area**. Regions represent provider geographic infrastructure areas.

5. **A — Object storage**. Object stores provide durable, scalable unstructured storage.

6. **A — To reduce unauthorised access surface**. Limit access through trusted application and identity controls.

7. **A — Unique accounts, MFA and least privilege**. Identity controls limit compromise impact.

8. **A — Maximum acceptable data-loss interval**. RPO constrains acceptable potential data loss.

9. **A — To prove recovery works in practice**. A successful backup job alone does not prove recoverability.

10. **A — Outbound network data transfer**. Usage and egress charges require monitoring.

11. **A — Review, test, monitor and plan rollback**. A controlled release uses evidence and recovery planning.

12. **A — Correlate impact, logs, metrics and recent changes**. Systematic diagnostics avoid false conclusions.

</details>
