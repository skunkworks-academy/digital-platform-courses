# Final knowledge check

Answer all twelve questions before expanding the key. Each correct response earns one mark; **10/12 or more** meets the 80% standard. Public page scores are self-reported and do not issue a certificate.

### 1. What makes cloud capacity elastic?

A. It can increase or decrease with demand  
B. It is always free  
C. It never requires networking  
D. It stores no information  

### 2. Which model provides a finished hosted application?

A. SaaS  
B. IaaS  
C. Local bare metal  
D. Direct-attached storage  

### 3. Who generally manages the guest OS of an IaaS VM?

A. Customer  
B. Internet registry  
C. Student examiner  
D. Public visitors  

### 4. What is a region?

A. Geographic cloud deployment area  
B. A password format  
C. A text editor  
D. A single user account  

### 5. What is least privilege?

A. Only necessary permissions  
B. All users as admin  
C. No sign-in checks  
D. Public API tokens  

### 6. Which storage suits photos and documents as objects?

A. Object storage  
B. CPU cache only  
C. RAM registers  
D. Router table  

### 7. RPO primarily measures what?

A. Tolerable period of lost data  
B. Total bandwidth  
C. Number of staff  
D. Disk model  

### 8. RTO primarily measures what?

A. Target time to restore service  
B. Cloud tax rate  
C. Storage unit  
D. Authentication method  

### 9. Does replication alone guarantee recovery from accidental deletion?

A. No  
B. Yes  
C. Only at night  
D. Only on Windows  

### 10. Which expense can surprise a cloud pilot?

A. Network egress and continued resource runtime  
B. Screen brightness  
C. Keyboard language  
D. User avatar  

### 11. How should secrets be managed?

A. Server-side protected store  
B. Public GitHub files  
C. Browser JavaScript source  
D. Email subject  

### 12. What must happen when a pilot ends?

A. Remove or hand over resources through a controlled teardown  
B. Forget the running resources  
C. Share admin passwords  
D. Disable billing alerts  

<details>
  <summary>Answer key and explanations — reveal after completing</summary>

1. **A. It can increase or decrease with demand** — Elasticity changes resource capacity as demand varies.

2. **A. SaaS** — SaaS delivers provider-managed application functionality.

3. **A. Customer** — The IaaS customer typically manages the guest OS.

4. **A. Geographic cloud deployment area** — Region choice has latency, data and availability implications.

5. **A. Only necessary permissions** — Narrow access reduces exposure.

6. **A. Object storage** — Blob/object stores support unstructured objects.

7. **A. Tolerable period of lost data** — RPO specifies the acceptable data-loss window.

8. **A. Target time to restore service** — RTO defines the service recovery target.

9. **A. No** — Deletion can replicate; backups need restore tests.

10. **A. Network egress and continued resource runtime** — Metered charges need budget controls.

11. **A. Server-side protected store** — Secret managers reduce accidental exposure.

12. **A. Remove or hand over resources through a controlled teardown** — A teardown limits future charges and attack surface.

</details>

If below 10/12, revisit the associated lesson and complete an equivalent practice activity. Capstone validation is also required for verified achievement.
