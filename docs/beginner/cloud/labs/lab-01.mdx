# Lab 1: Design a safe beginner cloud architecture

**Duration:** 85 minutes. **Mode:** no-charge cloud simulation or authorised sandbox.

## Scenario

A fictional Academy needs a public course catalogue and private learner progress.

## Hands-on lab procedure

1. Specify three user roles and three information classifications.
2. Choose an IaaS/PaaS/SaaS model with justification for each service.
3. Draw an HTTPS entry point, app, identity service, database, object storage and logging.
4. Identify region, optional zone availability and a business-residency restriction.
5. Mark ingress and egress flows, including a denied public database connection.
6. Describe two failure conditions and the expected continuity behavior.
7. Submit a legend explaining who operates every component.

## Acceptance criterion

Architecture meets public availability needs while denying unauthorised access to learner and payment records.

Provide: a scope statement, a labelled diagram or cost workbook, redacted evidence for each key design decision, one positive and one deliberately invalid/denied test, and 100–150 words of lessons learned. For failures, record the hypothesis, observed result, corrective action and safe rollback.

:::warning Safe cloud practice
Do not use production resources, real credentials or chargeable cloud services without written approval. A detailed spreadsheet or architecture simulation is a valid lab path.
:::
