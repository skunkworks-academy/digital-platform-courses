# Lab 2: Cloud cost and scale planning simulation

**Duration:** 80 minutes. **Mode:** no-charge cloud simulation or authorised sandbox.

## Scenario

A six-month public training campaign has variable traffic and a limited budget.

## Hands-on lab procedure

1. Build a spreadsheet with synthetic compute, storage, requests, egress, support and backup usage.
2. Calculate normal monthly cost and three-times-traffic scenario from stated unit assumptions.
3. Add alerts for spend above 70% and 90% of the limit; set an accountable owner.
4. Compare the resulting cost to a fixed-resource alternative without hiding operational labour.
5. Set example RTO and RPO for catalogue pages and learner grades.
6. Describe how to test a recovery plan on simulated resources.
7. Write an exception response for projected budget overrun.

## Acceptance criterion

Cost model is mathematically consistent and explicitly labels every provider rate as an example, not a guaranteed price.

Provide: a scope statement, a labelled diagram or cost workbook, redacted evidence for each key design decision, one positive and one deliberately invalid/denied test, and 100–150 words of lessons learned. For failures, record the hypothesis, observed result, corrective action and safe rollback.

:::warning Safe cloud practice
Do not use production resources, real credentials or chargeable cloud services without written approval. A detailed spreadsheet or architecture simulation is a valid lab path.
:::
