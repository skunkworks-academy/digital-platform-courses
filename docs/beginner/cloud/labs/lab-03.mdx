# Lab 3: Cloud security and outage tabletop

**Estimated time:** 90 minutes. **Environment:** Paper simulation or a permitted training environment; no billable or exposed infrastructure required.

## Procedure

1. Map users to least-privileged roles and show a prohibited access attempt.
2. Document a secure public frontend / private data store network boundary.
3. Simulate an unavailable compute instance and detect it using an alert scenario.
4. State RTO, RPO, backup frequency, restore evidence and escalation contacts.
5. Create a post-incident improvement list and an implementation approval checklist.

## Evidence of capability

**Acceptance criteria:** The scenario includes fail-closed access and recovery decisions based on measured objectives and observable tests.

Produce a labelled diagram, worksheet and short decision record with assumptions, quantitative measures where possible, one successful and one denied/failed test, remediation and clear cost implications. Use fictitious systems and avoid actual billable deployments unless they are separately authorised and controlled.

## Quality and self-reflection

Can a second person reproduce your design and verify the result? What remains a single point of failure? How would you know if the assumptions became invalid or the monthly budget was exceeded?
