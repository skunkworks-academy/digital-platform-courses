# Learner guide

**Course:** SKW-BEG-CLD-101 — Cloud Computing Fundamentals. **Level:** Beginner. **Time:** 6–8 hours.

## Preparation

Basic internet and computer knowledge; vendor accounts are optional. Every lab can be completed using a simulated architecture, spreadsheet and approved free documentation. Use fictional records and sandbox resources, never customer data, cloud account secrets or actual payment information. Do not incur cloud spend for these labs; all tasks include a paper or spreadsheet simulation option.

## Study sequence

1. Complete the ungraded baseline diagnostic at the top of the course home page.
2. Read all six modules, answer each pair of reflective questions before revealing guidance, and record an applied diagram, spreadsheet or decision table.
3. Perform the three guided labs and submit clear positive and negative test evidence.
4. Attempt the twelve-question final knowledge test: minimum passing score **10/12**, the first attainable integer meeting at least 80%.
5. Complete the capstone with at least **70/100** on the rubric and pass every safety-critical criterion.
6. Repeat the diagnostic and write a gap-closure plan supported by evidence.

## Deliverables and feedback

Use an accessible Markdown or PDF portfolio with the scope, assumptions, diagrams, estimated costs, tests, expected/actual outcomes, and a 100–150-word reflection for each practical. This public edition does not accept private evidence or issue formal certificates automatically. Assessment verification requires a separate authenticated Academy service and qualified reviewer.
