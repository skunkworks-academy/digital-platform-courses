# Cloud Computing Fundamentals

**SKW-BEG-CLD-101 · Beginner · 6–8 hours · Self-paced · proposed US$50**

Explain cloud service models, plan a safe small workload, understand basic identity, storage, networking and cost, and verify resilience in a simulated deployment.

**Who this is for:** IT beginners, small-business decision makers, junior service-desk staff and future cloud practitioners. **Prerequisites:** A browser and an ability to read basic diagrams. Hands-on tasks can be completed using simulated resources or approved free-tier environments without creating billable workloads.

## Capability outcomes

1. **Cloud concepts and service models** — A business currently hosts a brochure website on a local desktop. Compare a managed web service, a virtual machine and a fully managed website builder, listing cost, administration effort and control.
2. **Compute, regions and availability** — A booking site must remain usable during one server failure. Sketch a managed app, health checks, two instances and a data store; explain which components still represent single points of failure.
3. **Cloud storage and basic data protection** — A team needs to store public product images and private invoice PDFs. Propose two isolated storage locations with named owners, minimal read access and explicit retention.
4. **Identity, networks and shared responsibility** — A junior engineer needs to read storage usage and monitor uptime. Assign only read permissions required for those tasks rather than an owner/admin role.
5. **Cloud pricing, budgets and operational governance** — A fictional test environment runs a VM for 100 hours rather than 730 hours. Compare scenarios using an assumed hourly price of $0.05 plus fixed $8 storage: $13 vs $44.50, before taxes and transfer charges.
6. **Deployment, monitoring and recovery** — A fictional service wants recovery within four hours and at most one hour of data loss. Record RTO=4h and RPO=1h; then evaluate whether daily backup alone can satisfy the RPO.

## Learning and evaluation

Start with an ungraded baseline diagnostic, study all six modules, complete three practical labs and pass a knowledge check and capstone. Compare your results using the final diagnostic and record further learning needs. Self-reported scores are saved in your browser, not an official Academy gradebook.
