# Cloud Computing Fundamentals

**SKW-BEG-CLD-101 · Beginner · 6–8 hours · Self-paced · US$50 proposed**

Explain cloud concepts, choose appropriate service models, estimate cost, apply secure-access principles and develop a basic cloud architecture with recovery and monitoring.

**Audience:** IT newcomers, career changers, business administrators and anyone evaluating cloud services. **Prerequisites:** Basic internet and computer knowledge; vendor accounts are optional. Every lab can be completed using a simulated architecture, spreadsheet and approved free documentation.

## Your six core skills

1. From traditional IT to cloud computing — The comparison correctly identifies service dependencies, organisational trade-offs and the limits of cloud availability.
2. IaaS, PaaS, SaaS and shared responsibility — The service comparison assigns responsibilities correctly and recommends a service on measurable needs.
3. Cloud architecture: regions, networks, compute and storage — The diagram is coherent, segregates sensitive services and identifies realistic failure boundaries.
4. Identity, security and data protection in the cloud — The controls use minimal access, protect sensitive data and provide explicit authorised and denied tests.
5. Cloud pricing, scale, reliability and recovery — Budget totals reconcile, hidden cost sources are acknowledged and recovery objectives align with data value.
6. Deploy, observe, troubleshoot and govern cloud services — The operational runbook correlates evidence to hypotheses and contains an authorised, tested rollback path.

## Learning pathway

Take the five-item baseline before learning, study six lessons, complete three practical labs, attempt a 12-question knowledge check and prepare a final capstone. Repeat the five-item check after finishing and identify your strongest improvements.
