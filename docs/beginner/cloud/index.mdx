# Cloud Computing Fundamentals

**SKW-BEG-CLD-101 · Beginner · 6–8 hours · Self-paced · proposed US$50**

Learn cloud service models, regions, networking, security, storage, resilience and pricing—then plan a safe introductory deployment without paying for a cloud account.

## Learning outcomes

1. **Cloud services and how they work:** The comparison reflects cost and operational trade-offs, identifies a decision owner and lists any information still needed.
2. **Understand IaaS, PaaS, SaaS and deployment options:** The learner shows which responsibilities remain with the customer for each service model.
3. **Regions, zones, networking and reliability:** The architecture distinguishes public pages and restricted data and does not expose administrative services.
4. **Cloud identity, access and shared responsibility:** The permission design has named approval owners, no shared passwords and a demonstrable denied action.
5. **Compute, storage, databases and backup fundamentals:** The proposed storage choice, ownership and recovery tests are consistent with the sensitivity of each dataset.
6. **Cloud pricing, governance and a safe first deployment:** The plan has an authorised owner, capped assumptions, safe resource design and a scheduled removal procedure.
