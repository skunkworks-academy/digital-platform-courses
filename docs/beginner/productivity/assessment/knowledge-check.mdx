# Knowledge assessment

Attempt all 12 questions before revealing the answers. One answer per question, one point for each correct. **Pass: 10/12 or better.** This self-study knowledge check does not produce an official grade.

### 1. Which Microsoft 365 service primarily provides spreadsheets?

- **A.** Excel
- **B.** Word
- **C.** Teams chat
- **D.** Outlook mail

### 2. What is the purpose of MFA?

- **A.** To improve sign-in assurance
- **B.** To replace backups
- **C.** To create spreadsheet charts
- **D.** To share files anonymously

### 3. A row contains quantity in C2 and unit price in D2. Which formula multiplies them?

- **A.** =C2*D2
- **B.** =C2+D2+D2
- **C.** =SUM(C2:D2)/2
- **D.** C2xD2

### 4. What does $B$1 do in a formula copied down a sheet?

- **A.** Keeps column and row fixed
- **B.** Deletes the cell
- **C.** Makes text bold
- **D.** Hides a column

### 5. Which function adds cells A2 through A6?

- **A.** =SUM(A2:A6)
- **B.** =COUNT(A2:A6)
- **C.** =AVERAGE(A2:A6)
- **D.** =MAX(A2:A6)

### 6. What is a safe way to sort a sales list?

- **A.** Sort the entire structured table
- **B.** Sort just the price cells separately
- **C.** Delete the headings first
- **D.** Merge all rows

### 7. What should an external report email contain?

- **A.** A checked recipient and accurate action request
- **B.** An invented delivery commitment
- **C.** A publicly shared password
- **D.** No subject

### 8. Which sharing approach generally offers narrower access?

- **A.** Specific people with view access
- **B.** Anyone with a link can edit
- **C.** Anonymous public index
- **D.** Shared owner password

### 9. Which chart commonly compares categories?

- **A.** Bar chart
- **B.** Randomly scaled line chart
- **C.** Unlabelled gauge
- **D.** No-axis chart

### 10. What should you do when a workbook contains a duplicate transaction?

- **A.** Investigate and reconcile before reporting
- **B.** Count it twice automatically
- **C.** Hide it in the chart
- **D.** Ignore its effect on average

### 11. Why are heading styles preferable to bold-only headings?

- **A.** They create semantic document structure
- **B.** They change exchange rates
- **C.** They encrypt all content
- **D.** They guarantee a cloud backup

### 12. How should an automated report be approved?

- **A.** Reviewer verifies data, recipients and access
- **B.** Send it immediately after a formula recalculates
- **C.** Make it public for convenience
- **D.** Skip the human review

<details>
  <summary>Reveal answer key and learning feedback</summary>

1. **A. Excel** — Excel is designed for tables, formulas and analysis.

2. **A. To improve sign-in assurance** — MFA adds an authentication factor.

3. **A. =C2*D2** — The multiplication operator is *.

4. **A. Keeps column and row fixed** — It is an absolute reference.

5. **A. =SUM(A2:A6)** — SUM returns the arithmetic total.

6. **A. Sort the entire structured table** — Keep each record's fields together.

7. **A. A checked recipient and accurate action request** — Recipients and commitments must be verified.

8. **A. Specific people with view access** — Recipient-specific sharing limits exposure.

9. **A. Bar chart** — Bars make category comparisons readable.

10. **A. Investigate and reconcile before reporting** — Duplicates distort aggregates.

11. **A. They create semantic document structure** — Styles support navigation and accessibility.

12. **A. Reviewer verifies data, recipients and access** — Review protects accuracy and confidentiality.
