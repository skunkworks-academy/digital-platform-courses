# Lab 3: Integrated reporting mini-project

**Allocated time:** 100 minutes. **Equipment:** Any permitted spreadsheet/document editor or paper-based simulation.

## Client case

A small support team sends weekly ticket summaries to managers.

## Hands-on procedure

1. Create a six-row fictional ticket dataset with status, request type, time to resolve and date.
2. Calculate totals, average duration and count by category.
3. Produce a filtered view for outstanding work without deleting other rows.
4. Build a chart with an appropriate axis and citation to the worksheet.
5. Create a manager-facing document that summarises findings and limits.
6. Design a permissioned sharing workflow and acceptance criteria.
7. Test one incorrect input and one unauthorised link scenario; document prevention and recovery.

## Test, evidence and acceptance

**Pass requirement:** Complete, reproducible office workflow with verified calculations, coherent communication and no excessive file permissions.

Create a private evidence folder containing the original fictional inputs, final documents, a row-by-row or step-by-step results table, two redacted screenshots or equivalent text description and a 100-word reflection. At minimum, a valid test must succeed, an invalid or unauthorized test must fail safely, and calculations must be independently reproducible.

## Debugging protocol

If a result differs from expectation, confirm inputs and data types, check permissions, reproduce a smaller case, correct one variable and repeat the test. Log the actual outcome rather than marking the step as completed solely because a worksheet or document looks polished.
