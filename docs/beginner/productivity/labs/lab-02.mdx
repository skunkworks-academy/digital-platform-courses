# Lab 2: Office communication and collaborative approval

**Allocated time:** 70 minutes. **Equipment:** Any permitted spreadsheet/document editor or paper-based simulation.

## Client case

Prepare a customer-safe update and a scheduled internal review using made-up data.

## Hands-on procedure

1. Draft a one-page document using true headings, a short factual table and meaningful link text.
2. Compose an external email that avoids guaranteeing an unapproved date or price.
3. Produce an agenda with time zone, attendees, objective and two decision items.
4. Define the edit/view roles for fictional staff and an external party.
5. Simulate an incorrect recipient and record the stop-and-review action.
6. Submit a redacted review checklist and explain how the correct document version is selected.

## Test, evidence and acceptance

**Pass requirement:** Clear accessible communication, appropriate recipients and a demonstrable approval step before distribution.

Create a private evidence folder containing the original fictional inputs, final documents, a row-by-row or step-by-step results table, two redacted screenshots or equivalent text description and a 100-word reflection. At minimum, a valid test must succeed, an invalid or unauthorized test must fail safely, and calculations must be independently reproducible.

## Debugging protocol

If a result differs from expectation, confirm inputs and data types, check permissions, reproduce a smaller case, correct one variable and repeat the test. Log the actual outcome rather than marking the step as completed solely because a worksheet or document looks polished.
