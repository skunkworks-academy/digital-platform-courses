# Lab 1: Create an accurate small-business budget workbook

**Allocated time:** 90 minutes. **Equipment:** Any permitted spreadsheet/document editor or paper-based simulation.

## Client case

A fictional five-person training business needs a basic expense tracker, monthly category totals and a visual report.

## Hands-on procedure

1. Build a worksheet with six sample expenses, dates, categories, quantities and unit costs.
2. Calculate line totals and overall total using formulas, not hand-entered answers.
3. Add a fixed currency/tax parameter and explain a suitable absolute reference.
4. Use a conditional IF or COUNTIF formula to flag expenses above a fictional approval threshold.
5. Create a small column chart by category with a source caption.
6. Inject an invalid number and a duplicate row; demonstrate detection and correction.
7. Write a 150-word financial summary with assumptions and variance caveats.

## Test, evidence and acceptance

**Pass requirement:** All numbers reconcile; the chart is correctly labelled and invalid entries cannot be mistaken for valid financial facts.

Create a private evidence folder containing the original fictional inputs, final documents, a row-by-row or step-by-step results table, two redacted screenshots or equivalent text description and a 100-word reflection. At minimum, a valid test must succeed, an invalid or unauthorized test must fail safely, and calculations must be independently reproducible.

## Debugging protocol

If a result differs from expectation, confirm inputs and data types, check permissions, reproduce a smaller case, correct one variable and repeat the test. Log the actual outcome rather than marking the step as completed solely because a worksheet or document looks polished.
