# Module 3: Excel worksheets, data types and reference skills

**Estimated study:** 45–70 minutes. **Capability outcome:** Each transaction multiplies its quantity and price correctly, formulas copy predictably, and input fields are typed consistently.

## Explanation and concepts

An Excel workbook holds worksheets, cells, ranges, formulas, tables and possibly charts. A text value behaves differently from a true number or date. Choose clear column headings and enter one field per column, one observation per row. Blank cells, mixed currency text and merged data cells commonly break calculations and sorting. A relative reference such as B2 changes when copied; an absolute reference such as $B$1 remains fixed. Formulas begin with an equals sign. Use real dates rather than text that merely looks like a date. The purpose of formatting is to communicate meaning, not to fix an incorrect underlying data type.

## Worked business situation

A small seller lists five fictional purchases. One quantity is stored as text and one currency value uses an inconsistent separator. The worksheet looks correct but totals fail; identify and fix the underlying types.

## Follow-along practical

1. Create a table with columns Item, Category, Quantity, Unit Price, Date and Total.
2. Enter five invented transactions, with consistent currency units and a valid date column.
3. In Total, calculate row amount with =C2*D2 and copy the formula down the table; adjust column coordinates if needed.
4. Write a fixed tax-rate or discount parameter into one named cell, then reference it with an absolute reference in a practice calculation.
5. Inspect each cell's data type and record two deliberate errors and their corrections.

## Validate and improve

Each transaction multiplies its quantity and price correctly, formulas copy predictably, and input fields are typed consistently. Build an evidence table with **expected result**, **observed result**, **data source**, **decision**, **next action**. Include one valid and one deliberately invalid input. If a simulated environment is used, label the simulation clearly.
