# Module 5: Sorting, filtering, visuals and basic reporting

**Estimated study:** 45–70 minutes. **Capability outcome:** The table retains data integrity after sorting, the chart states units and denominators, and conclusions match the evidence.

## Explanation and concepts

Sort changes row order; filter hides rows that do not match a condition without deleting them. When working with records, select the whole table instead of sorting a single isolated column, otherwise records can become detached. Structured tables with headings improve safe filtering and formula readability. Choose bar charts for comparing categories, line charts for ordered time trends and a simple table when precise individual values matter. Always label units, dates and source, avoid truncated axes that distort perception, and explain how many observations were included. A dashboard is a decision aid, not proof of causation.

## Worked business situation

A team claims response times improved based on a chart, but one month has only two records and another has twenty. Compare sample sizes and resist drawing a definitive trend from unequal evidence.

## Follow-along practical

1. Create a structured table from fictional monthly expenses or service tickets.
2. Sort the entire table by one numeric column, and verify that identifiers remain attached to their rows.
3. Filter one category, then clear the filter and confirm that the full record count returns.
4. Build one bar chart with a descriptive title, source note, category axis and explicit unit.
5. Write a five-sentence management report distinguishing fact, limitation and proposed follow-up.
