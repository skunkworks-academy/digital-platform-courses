# Module 1: Microsoft 365, accounts and cloud file basics

**Estimated study:** 45–70 minutes. **Capability outcome:** A colleague can identify the authoritative file, explain whether it is local or cloud-based and determine who may edit it.

## Explanation and concepts

Microsoft 365 is a collection of productivity and collaboration services; available apps depend on the purchased plan and organisational policies. Word is primarily for structured documents, Excel is a spreadsheet, PowerPoint communicates visually, Outlook handles mail and calendar, Teams provides collaboration, while OneDrive and SharePoint support file storage and team sites. Know the difference between a local file, a cloud file, a shared link and a synced copy. A browser view is not necessarily an offline backup. Account recovery and multifactor authentication help protect access. Carefully choose file names, folders and revision history. 'Save a Copy' creates a new artefact, while shared collaboration normally works on one approved source of truth.

## Worked business situation

A fictional office has three copies of a quotation called FINAL, FINAL-2 and NEWFINAL. Before editing, identify the authoritative file and owner, create a folder structure, and agree a naming and versioning convention.

## Follow-along practical

1. Draw a small map of the six Microsoft 365 services and write one business use case for each.
2. Create a fictional folder structure such as Sales/2026/Quotes and Operations/Meetings, with a named owner.
3. Rename three practice files using lowercase or human-readable consistent names and clear version dates.
4. Document the difference between edit/view permissions and link-based sharing, with one external-sharing risk.
5. Test recovering an earlier draft through your own practice file history, or describe the restoration process in a simulation.
