# Module 6: Teams collaboration, sharing permissions and productivity workflow

**Estimated study:** 45–70 minutes. **Capability outcome:** A governed reporting workflow can be reproduced safely, with explicit permissions, approval, logging and a rollback plan.

## Explanation and concepts

Collaboration involves identity, information classification and ownership. Teams chat is appropriate for conversations; channel files commonly live in SharePoint, whereas personal files may originate in OneDrive. A link for people with existing access is different from an anonymous link that anyone holding it can open. Choose view-only access unless editing is needed, review external guest access and revoke obsolete shares. Coauthoring and version history help avoid lost edits but do not replace retention and tested recovery. Build a repeatable end-to-end workflow from a request, to a versioned document, to an evidence-backed spreadsheet, to approval and delivery.

## Worked business situation

A team needs to share a fictional monthly report with an external accountant. The report should not be publicly searchable or editable by all staff. Propose the minimum recipient-specific access, expiry and review.

## Follow-along practical

1. Draw a document hand-off between requestor, analyst, reviewer and external recipient.
2. Define a data-classification decision before a file leaves the team.
3. Create an approval checklist covering totals, formulas, recipients, permissions, version and expiry.
4. Simulate a correct shared-link invitation and an unauthorised access attempt; record expected deny behaviour.
5. Build a 10-minute monthly reporting runbook with owner, exception path and evidence checklist.

## Validate and improve

A governed reporting workflow can be reproduced safely, with explicit permissions, approval, logging and a rollback plan. Build an evidence table with **expected result**, **observed result**, **data source**, **decision**, **next action**. Include one valid and one deliberately invalid input. If a simulated environment is used, label the simulation clearly.
