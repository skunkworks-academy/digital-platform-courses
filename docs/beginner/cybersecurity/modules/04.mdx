# Module 4: Securing phones, computers and home networks

**Estimated time:** 45–70 minutes. **Outcome:** The plan reduces easy account/device compromise, limits guest exposure and proves at least one recoverable test file.

## Core concepts and why they matter

Security hygiene begins with supported software, timely updates, screen locking, full-disk encryption, device inventory, reputable endpoint protection and the ability to locate or remotely wipe lost devices where authorised. Application installations require trustworthy sources and appropriate permissions. For home or small-office networks, replace router default administrative credentials, use up-to-date Wi-Fi security (WPA2-AES or WPA3 as supported), restrict guest access, disable unnecessary remote management and update firmware.

## Worked workplace scenario

A family shares one Wi-Fi network between work laptops, children and smart speakers. Recommend sensible network separation, router maintenance and a device-loss procedure.

## Guided hands-on application

1. Create a device hygiene checklist covering patch level, auto-lock, backup and encryption.
2. Review hypothetical router settings and flag weak credentials, old wireless security and open guest access.
3. Design a guest Wi-Fi separation plan with no need for invasive scanning.
4. Describe how to test a data backup restoration safely using a sample file.

## Verification and failure test

The plan reduces easy account/device compromise, limits guest exposure and proves at least one recoverable test file. Create a table identifying expected result, actual result, date, supporting evidence and next action. Use one deliberately invalid or unexpected input to confirm the control does not silently fail.

:::warning Safety and ethics
Do not disable firewalls or make remote management public to simplify access.
:::
