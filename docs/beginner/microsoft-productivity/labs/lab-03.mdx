# Lab 3: Create a simple enrolment dashboard

**Approximate time:** 100 minutes. **Environment:** Use ten fabricated learner-related counts, not real learner names.

## Steps

1. Prepare a clean table with day, enquiries, enrolments and completions.
2. Calculate daily totals, weekly totals and conversion = enrolments / enquiries with division-by-zero handling.
3. Identify missing dates and duplicates; write a correction log.
4. Build one correctly labelled bar/line chart and a summary table.
5. Present an executive interpretation that clearly separates observed trends from assumptions.

## Acceptance criteria

Reproducible figures, transparent data quality handling and an accessible narrative summary.

## Evidence checklist

Provide the editable workbook or text document (with fictional data), a screenshot or exported view, one normal scenario, one erroneous/denied scenario and an explanation of how the final artefact can be maintained. Redact personal or privileged information and document owner/approval.

## Self-review

Check arithmetic independently; verify chart units and table sources; and make sure external-sharing assumptions are explicit rather than implied by a successful save action.
