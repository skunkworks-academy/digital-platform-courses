# Lab 1: Build an Excel business budget

**Approximate time:** 90 minutes. **Environment:** Use Excel or a compatible spreadsheet with synthetic budgets and no client data.

## Steps

1. Create expense categories, descriptions, quantity, unit price and monthly amount.
2. Use multiplication and SUM with a fixed tax or contingency rate to calculate totals.
3. Copy one formula using relative references and one using an absolute reference; document the difference.
4. Introduce one duplicate receipt and one blank amount; flag both with a validation rule.
5. Add a simple labelled chart and test its values against the source table.

## Acceptance criteria

Accurate totals and an evidence log for copy-down formulas, errors and corrected results.

## Evidence checklist

Provide the editable workbook or text document (with fictional data), a screenshot or exported view, one normal scenario, one erroneous/denied scenario and an explanation of how the final artefact can be maintained. Redact personal or privileged information and document owner/approval.

## Self-review

Check arithmetic independently; verify chart units and table sources; and make sure external-sharing assumptions are explicit rather than implied by a successful save action.
