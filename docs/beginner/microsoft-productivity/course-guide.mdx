# Getting started

**SKW-BEG-M365-101 · 8–10 hours**

Access to Excel and Microsoft 365, compatible desktop/web apps, or a spreadsheet alternative for written practice; no administrative permissions needed. You may simulate advanced sharing tasks using an access matrix if your account does not have the required privileges. Use fictional names and invented expense data rather than live customer/student information.

## Study and evidence sequence

1. Take the five-item ungraded **Before learning** check.
2. Study six modules, including their practical tasks and two written reflection questions.
3. Complete three applied labs, keeping before/after workbook evidence, a negative test and a correction log.
4. Complete the twelve-question conceptual assessment; passing score **10/12**.
5. Submit the capstone portfolio and rubric: **70/100** minimum plus all critical data-protection checks.
6. Repeat the diagnostic, record improvements and identify one next learning goal.

## Spreadsheet quality checklist

Confirm the workbook contains one clear header row, consistent data types, traceable formulas, a known source, a correct date range, checked totals, meaningful chart units and an identified owner for publication. Record incorrect inputs rather than hiding them.

## Accessibility, assessment and support

Use Excel's accessible formatting and meaningful document headings. An alternate workbook app or paper-calculated report may be accepted when software access is unavailable, provided the formula reasoning and evidence are clear. A human assessor must validate and record official Academy achievements; browser progress is formative only. Support: [training@skunkworks.africa](mailto:training@skunkworks.africa).
