# Module 2: Word, Outlook and everyday communication

**Study time:** 50–70 minutes. **Outcome:** apply this productivity capability using accurate, accessible and appropriately shared information.

## Learn the principles

A professional document needs clear headings, semantic styles, readable font size, accessible links, alt text for meaningful images and a defined audience. Track Changes and version history serve different purposes: one records edits, the other helps inspect versions and restore file states. In Outlook, check recipient, subject, attachments, requested action and confidentiality; distinguish To, Cc and Bcc. Use sensible meeting invitations with agenda and time zone.

## Worked business case

A manager asks for a one-page training announcement and an email invitation to seven employees. Draft an announcement with heading styles, accessible action text and a calendar invite with explicit time zone.

## Practical walkthrough

1. Write a fictional service update and format its summary, next actions and contact. Create a send-checklist that prevents wrong recipients or missing attachments.
2. Capture the task objective, input data or document version, expected result and who will review it.
3. Produce a draft artefact or spreadsheet formula, then check one ordinary and one erroneous/unauthorised condition.
4. Correct the observed issue and preserve a simple change history.
5. Produce a short user-facing explanation of the final result and any outstanding limitation.

## Errors to avoid

Do not embed private attendee lists in a publicly shareable document or mistake Bcc for comprehensive data-loss prevention.

## Knowledge and reflection checkpoint

- Which two checks must be performed before a document or calculation is shared?
- How would a colleague reproduce your work and detect a missing or incorrect value?
