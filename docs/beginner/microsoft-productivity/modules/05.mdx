# Module 5: Teams, OneDrive and collaborative work

**Study time:** 50–70 minutes. **Outcome:** apply this productivity capability using accurate, accessible and appropriately shared information.

## Learn the principles

Teams channels bring conversations and shared files together. Files often live in a connected SharePoint site; OneDrive is commonly for individual work files and controlled sharing. Choose owners, members and guests deliberately, and review external sharing before inviting collaborators. Comments, mentions and version history support review, but not every user should be able to approve final content. Record decisions and meeting follow-up actions.

## Worked business case

A four-person team is collaborating on a client proposal; one external reviewer needs access to only a single approved draft. Choose a limited share, define owner and an end date, and verify the reviewer cannot browse unrelated files.

## Practical walkthrough

1. Create a fictional project folder map and role matrix; prepare a safe link for an approved reviewer; document how you would revoke access and examine version history.
2. Capture the task objective, input data or document version, expected result and who will review it.
3. Produce a draft artefact or spreadsheet formula, then check one ordinary and one erroneous/unauthorised condition.
4. Correct the observed issue and preserve a simple change history.
5. Produce a short user-facing explanation of the final result and any outstanding limitation.

## Errors to avoid

Never assume access to a Teams channel automatically means permission to every confidential file used by the project.

## Knowledge and reflection checkpoint

- Which two checks must be performed before a document or calculation is shared?
- How would a colleague reproduce your work and detect a missing or incorrect value?

<details>
  <summary>Expected assessment feedback</summary>

A strong answer identifies the data source, owner, sharing permissions, calculation or content accuracy, repeatable verification and responsible approval. Appearance alone is not evidence of correctness.
