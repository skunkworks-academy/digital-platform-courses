# Module 1: Getting started with Microsoft 365

**Study time:** 50–70 minutes. **Outcome:** apply this productivity capability using accurate, accessible and appropriately shared information.

## Learn the principles

Microsoft 365 combines productivity applications and cloud services such as Word, Excel, Outlook, Teams, SharePoint and OneDrive, with capabilities depending on licensing. Differentiate your organisation account from a personal Microsoft account. A file saved only on a laptop is not automatically available on other devices; saving to OneDrive or a controlled SharePoint library enables authorised sync and collaboration. Know who owns shared material, what the sharing link grants and why MFA protects work accounts.

## Worked business case

A fictional design agency has five staff, one shared training schedule and separate private finance records. Map which files should be personal, team-controlled and finance-restricted.

## Practical walkthrough

1. Create a table with document, intended owner, collaboration location, permitted viewers and retention expectation. Explain how you would verify sharing before sending a link.
2. Capture the task objective, input data or document version, expected result and who will review it.
3. Produce a draft artefact or spreadsheet formula, then check one ordinary and one erroneous/unauthorised condition.
4. Correct the observed issue and preserve a simple change history.
5. Produce a short user-facing explanation of the final result and any outstanding limitation.

## Errors to avoid

A link set to 'anyone with the link' is different from a link restricted to named people. Do not use wide-open links for internal customer data.

## Knowledge and reflection checkpoint

- Which two checks must be performed before a document or calculation is shared?
- How would a colleague reproduce your work and detect a missing or incorrect value?
