# Module 3: Excel workbooks, formulas and references

**Study time:** 50–70 minutes. **Outcome:** apply this productivity capability using accurate, accessible and appropriately shared information.

## Learn the principles

A workbook holds worksheets made of rows, columns and cells. Numbers, dates and text have different behaviour. Formulas start with '='. Relative references such as A2 adjust when copied; absolute references like $B$1 stay fixed. Core functions include SUM, AVERAGE, COUNT, IF and COUNTIF. A percentage cell and a formatted currency cell can display misleading values when the underlying data type is wrong. Check formulas against an independent example.

## Worked business case

A shop records quantities 2, 4 and 3 with unit prices 50, 25 and 100. Calculate the line amounts 100, 100 and 300, and the total 500 using formulas, not manually overwritten results.

## Practical walkthrough

1. Create a five-line fictional sales worksheet with headings, currency values, row totals, tax rate in a fixed cell and grand total. Copy formulas and verify three results with manual arithmetic.
2. Capture the task objective, input data or document version, expected result and who will review it.
3. Produce a draft artefact or spreadsheet formula, then check one ordinary and one erroneous/unauthorised condition.
4. Correct the observed issue and preserve a simple change history.
5. Produce a short user-facing explanation of the final result and any outstanding limitation.

## Errors to avoid

Avoid pasting generated values over formulas without documenting the source and make sure percentage inputs use a consistent scale.

## Knowledge and reflection checkpoint

- Which two checks must be performed before a document or calculation is shared?
- How would a colleague reproduce your work and detect a missing or incorrect value?
