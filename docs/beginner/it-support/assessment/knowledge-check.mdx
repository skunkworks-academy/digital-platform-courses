## Printable question version

The same questions are provided below for offline or accessible written practice. Use the interactive quiz above for immediate browser feedback; neither option issues a formal credential.

### 1. Which component holds working data temporarily?

A. SSD  
B. RAM  
C. Router  
D. Monitor  

### 2. What is an incident?

A. A planned purchase  
B. An unplanned service interruption  
C. A routine permission request  
D. A software licence  

### 3. What should happen before installing a random driver?

A. Check vendor, version, approval and rollback  
B. Disable all protection  
C. Accept every download  
D. Delete the registry  

### 4. What should a support ticket capture?

A. Symptom, impact, timestamps and attempts  
B. Only the user's name  
C. Only ticket colour  
D. The user's password  

### 5. What assigns many network devices their IP configuration?

A. DHCP  
B. SMTP  
C. HTML  
D. USB  

### 6. What does DNS generally resolve?

A. Names to network records  
B. Hard disks  
C. RAM faults  
D. Printer ink levels  

### 7. A site fails by name but IP connectivity works. What should be checked?

A. DNS among other causes  
B. Replace processor immediately  
C. Unplug all storage  
D. Install antivirus without approval  

### 8. Why avoid deleting system files to free space?

A. Destructive and may break the OS  
B. It always speeds up the laptop  
C. It improves backup quality  
D. It resolves every crash  

### 9. Which is a good priority input?

A. Impact and urgency  
B. Customer volume alone  
C. Technician preference  
D. Brand of laptop  

### 10. Why verify a fix with the user?

A. To confirm the original task works in context  
B. To avoid documenting it  
C. Because tools are always wrong  
D. To reveal credentials  

### 11. What is safer for patching?

A. Approval, backup, test and rollback  
B. Unplanned production change  
C. No evidence  
D. Disable logging  

### 12. What should escalation include?

A. Diagnostic evidence and next responsible action  
B. Only the phrase doesn't work  
C. A user password  
D. An unrelated complaint  

<details>
  <summary>Answer key and feedback — reveal after attempting</summary>

1. **B. RAM** — RAM is volatile working memory.

2. **B. An unplanned service interruption** — An incident disrupts normal service.

3. **A. Check vendor, version, approval and rollback** — Driver changes require verification.

4. **A. Symptom, impact, timestamps and attempts** — Evidence and context support diagnosis.

5. **A. DHCP** — DHCP provides configuration leases.

6. **A. Names to network records** — DNS maps names to records including IP addresses.

7. **A. DNS among other causes** — Name resolution is one likely fault domain.

8. **A. Destructive and may break the OS** — Safe diagnostics precede irreversible changes.

9. **A. Impact and urgency** — Priority is driven by impact and urgency.

10. **A. To confirm the original task works in context** — Closure needs acceptance evidence.

11. **A. Approval, backup, test and rollback** — Controlled change lowers service risk.

12. **A. Diagnostic evidence and next responsible action** — A clear hand-off avoids repeated work.

</details>
