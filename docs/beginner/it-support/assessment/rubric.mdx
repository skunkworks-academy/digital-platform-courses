# Marking guide and assessment governance

**Knowledge:** 10/12 minimum. **Capstone:** 70/100 minimum with every critical security and privacy control passed. **Labs:** three reproducible practice reports; each includes success and safe failure cases.

Use the capstone's weighted domains: scope 15 points; solution correctness 25; reproducibility 25; verification 20; operations and reflection 15. Feedback must cite observable evidence and identify the exact correction required. A competent human assessor, not an AI-only grader, makes the verified completion decision. Allow reasonable accessibility accommodations without reducing outcome standards.
