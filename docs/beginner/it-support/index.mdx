# IT Support & Computer Troubleshooting Fundamentals

**SKW-BEG-IT-101 · Beginner · 8–10 hours · self-paced · proposed US$50**

Diagnose common hardware, operating-system, network and user-account problems safely, communicate with users and document evidence-led solutions.

**Audience:** Aspiring help-desk technicians, new office administrators and non-technical staff. **Prerequisites:** Access to a Windows or Linux computer, a browser and a disposable troubleshooting workspace; no admin rights needed for most lessons.

## Outcomes

1. Computer components, operating systems and peripherals: A configuration record identifies the component affected and separates symptoms from likely root causes.
2. Support tickets and diagnostic reasoning: Every ticket includes impact, symptoms, attempted steps, timestamps and verifiable acceptance criteria.
3. Windows and Linux fundamentals for support: Evidence shows operating-system state and that no unapproved destructive action was performed.
4. Networking basics: IP, DNS, Wi-Fi and Internet access: A network diagnostic table maps each test to the OSI-relevant layer, expected result and next action.
5. Applications, accounts, updates and backup: The resulting runbook has safe checkpoints, approved actions, escalation and a tested rollback path.
6. Customer communication, escalation and evidence-based closure: The hand-off allows a second technician to continue without re-asking already answered questions.

## Begin your learning journey

Take the ungraded five-question baseline, work through six lessons, complete three practical exercises, take the twelve-question final knowledge assessment, assemble the capstone and repeat the diagnostic to evaluate learning growth. Use the progress checklist to monitor what you have studied.
