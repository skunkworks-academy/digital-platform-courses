# Module 1: Computer components, operating systems and peripherals

**Estimated time:** 45–70 minutes. **Outcome:** A configuration record identifies the component affected and separates symptoms from likely root causes.

## Core concepts and why they matter

A computer combines processor, memory (RAM), persistent storage, network adapters and input/output devices. CPU handles instructions; RAM holds temporary working data; SSDs/HDDs store data persistently. A device's operating system coordinates hardware and applications; drivers translate between devices and OS. Distinguish a peripheral issue from a physical connector, software driver, power supply or application setting. Record device model, asset ID, operating-system version and user impact before recommending replacement.

## Worked workplace scenario

A laptop becomes slow when many browser tabs are open. The technician inspects memory pressure and process activity before proposing storage replacement.

## Guided hands-on application

1. Label CPU, RAM, SSD, adapter and peripheral in a simple diagram.
2. Explain the difference between available memory and free disk space.
3. Record a fictional device specification including OS version, update status, battery and display.
4. Choose two non-destructive tests for a missing printer.

## Verification and failure test

A configuration record identifies the component affected and separates symptoms from likely root causes. Create a table identifying expected result, actual result, date, supporting evidence and next action. Use one deliberately invalid or unexpected input to confirm the control does not silently fail.

:::warning Safety and ethics
Never open hardware or change BIOS settings in an owned business device without authorisation.
:::
