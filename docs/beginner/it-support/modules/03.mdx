# Module 3: Windows and Linux fundamentals for support

**Estimated time:** 45–70 minutes. **Outcome:** Evidence shows operating-system state and that no unapproved destructive action was performed.

## Core concepts and why they matter

Identify OS version, user profile, running processes, storage usage, startup applications, updates and event logs. Windows offers Task Manager, Settings, Event Viewer, Resource Monitor and built-in troubleshooters. Linux offers commands such as pwd, ls, df -h, free -h, top and journalctl on appropriate systems. Permissions restrict changes: regular users should not elevate automatically. A command's output is evidence and can be recorded, but not every command is available on every OS or edition.

## Worked workplace scenario

A user reports low disk space. The technician checks usage categories and known temporary directories rather than deleting system files.

## Guided hands-on application

1. Find the operating-system version and device uptime using read-only settings.
2. Identify the largest fictional file category in a sample storage report.
3. Interpret process CPU and RAM usage, and name one possible performance bottleneck.
4. Design a safe update and rollback process for a business computer.

## Verification and failure test

Evidence shows operating-system state and that no unapproved destructive action was performed. Create a table identifying expected result, actual result, date, supporting evidence and next action. Use one deliberately invalid or unexpected input to confirm the control does not silently fail.

:::warning Safety and ethics
Avoid 'cleaner' tools, copied shell commands or registry edits without validation and rollback.
:::
