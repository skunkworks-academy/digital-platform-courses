# Module 4: Safe devices, updates and backups

**Learning time:** 45–60 minutes. **Outcome:** understand and apply this protective capability in an authorised home or small-business setting.

## Understand the threat and control

Maintain supported software versions, automatic updates, device encryption, endpoint protection, secure screen lock and safe installation sources. Malware and ransomware can spread through malicious downloads and compromised accounts. Follow a 3-2-1 backup principle when appropriate: multiple copies, different media, one offsite; also test restoration and consider immutable or offline copies. A backup that cannot be restored is not a dependable recovery plan.

## Practical case

A laptop displays a suspicious browser extension and unusually high CPU usage. First contain and document; do not disable all security software or run untrusted 'cleanup' downloads.

## Guided exercise

1. Audit a personal or mock device: update status, auto-lock, disk encryption, trusted app sources, backup recency and restoration method.
2. Create a simple table with **risk, evidence, control, owner and review date**.
3. Model a successful authorised action and an unauthorised or failed action; explain how the control responds.
4. Record observations, assumptions and recommended next steps separately.

## Avoid these mistakes

Demonstrate one harmless restore of a synthetic text file to an isolated location and record the result.

## Knowledge checkpoint

1. Explain the primary control and the harm it reduces.
2. What evidence would prove the control worked, and what would trigger escalation?
