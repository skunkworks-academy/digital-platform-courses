# Lab 2: Personal device hardening and backup

**Time:** 70 minutes. **Required environment:** Use an authorised personal device or an offline simulated device checklist.

## Procedure

1. Record OS version and patch status without publishing device serial numbers.
2. Check automatic screen lock, account separation, update settings and disk-encryption status.
3. Document a password-manager and MFA adoption plan without storing credentials.
4. Create and restore a synthetic practice file from backup.
5. Record two recommendations ranked by risk, effort and owner.

## Assessment evidence

Create a short lab portfolio with the original scenario, purpose, initial conditions, approved scope, expected result, actual result, and a safe negative or failure test. Include one improvement you would make to the operating procedure.

**Acceptance:** A reviewer sees baseline versus improved settings and reproducible restore evidence without secrets.

## Troubleshooting and reflection

If the scenario behaves unexpectedly, identify what new evidence you need to isolate the cause. Never disable account protection, run live phishing links or test third-party assets just to obtain a passing result. Keep evidence private, redact identifiers and justify the response.
