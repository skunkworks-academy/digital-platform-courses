# Lab 3: Small-business security incident tabletop

**Time:** 80 minutes. **Required environment:** A fictional business account received unexpected MFA prompts and an altered supplier invoice.

## Procedure

1. Create an incident ticket with time, people, scope and observed facts.
2. Identify two possible attack paths without asserting either as proven.
3. Define immediate safe containment and independent finance verification.
4. Write a recovery checklist and user communication requiring approval.
5. Present lessons learned and an updated protective control map.

## Assessment evidence

Create a short lab portfolio with the original scenario, purpose, initial conditions, approved scope, expected result, actual result, and a safe negative or failure test. Include one improvement you would make to the operating procedure.

**Acceptance:** Timeline, response authority, protection of evidence, and clearly segregated assumptions versus confirmed facts.

## Troubleshooting and reflection

If the scenario behaves unexpectedly, identify what new evidence you need to isolate the cause. Never disable account protection, run live phishing links or test third-party assets just to obtain a passing result. Keep evidence private, redact identifiers and justify the response.
