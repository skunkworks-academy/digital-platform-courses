# Cybersecurity Essentials & Online Safety

**SKW-BEG-CYB-101 · Beginner · 6–8 hours · Self-paced · USD 50 proposed**

Recognise common digital threats, improve everyday account/device protection, respond correctly to suspicious events and document basic cyber risk decisions.

**Audience:** First-time technology learners, remote workers and small-business staff. **Prerequisites:** A smartphone or computer and a browser. All security exercises use simulated messages and authorized devices.
