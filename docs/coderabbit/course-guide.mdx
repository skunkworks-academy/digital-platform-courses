# CodeRabbit Course Guide

Use a disposable repository containing non-confidential sample code. You need permission to install or use CodeRabbit on that repository; otherwise study supplied examples and simulate findings. Never connect a repository whose organizational policy prohibits third-party AI processing.

## Responsibility boundary

CodeRabbit output is a recommendation. The author and authorized human reviewers remain accountable for correctness, security, privacy, licensing, and release. Do not merge generated fixes without understanding the diff and running relevant tests.

## Assessment blueprint

| Competence | Evidence |
|---|---|
| Safe scope and access | Permission/privacy decision record |
| Configuration | Valid, version-controlled configuration with rationale |
| Finding triage | Reproduce, classify, respond, verify |
| Workflow integration | Human-owned merge policy and checks |
| Improvement | Balanced metrics and tuning proposal |

Pass the 10-question knowledge check at 80% and the capstone at 70/100, meeting all critical criteria. Course v1.0, published 31 August 2026; review by 31 August 2027 or after material CodeRabbit changes.
