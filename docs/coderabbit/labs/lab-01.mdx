# Lab 1 — Safe Onboarding

**Time:** 30 minutes

For a disposable sample repository, inventory source, PR, issue, log, and knowledge-base data. Classify each and state whether it may be processed by the approved service. Record repository owner, installation owner, access-review date, excluded repositories/data, incident contact, and removal procedure.

If authorized, connect only the practice repository and inspect granted permissions. Otherwise, complete a paper simulation from the GitHub App permission screen or vendor documentation.

<div className="evidence"><strong>Evidence:</strong> one-page onboarding decision, redacted permission inventory, approval or simulation statement, and an explicit go/no-go decision with conditions.</div>
