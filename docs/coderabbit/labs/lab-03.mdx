# Lab 3 — Finding to Verified Fix

**Time:** 45 minutes

Select three findings: one confirmed, one uncertain, and one low-value or false-positive candidate. For each, capture the claim, assumed conditions, impact, priority, and evidence plan.

For the confirmed finding, reproduce it and add a regression test before or with the fix. For the uncertain finding, ask a precise clarifying question and verify independently. For the low-value finding, either improve the code or dismiss it with evidence and propose configuration tuning if it represents repeated noise.

<div className="evidence"><strong>Evidence:</strong> triage table, review conversation, code/test diff, validation output, and final disposition. Do not expose private code beyond the authorized learning environment.</div>
