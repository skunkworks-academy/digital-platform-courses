# CodeRabbit AI Code Review

**SKW-CR-201 · Intermediate · 8 hours · Self-paced**

Configure CodeRabbit, interpret findings critically, resolve review threads with proof, and integrate AI assistance into a human-owned quality system.

## Outcomes

You will be able to install with least privilege, explain review context and limits, write validated `.coderabbit.yaml` policies, triage findings by evidence and risk, use commands and conversations effectively, design pre-merge controls, and measure value without automating accountability.

| Module | Focus | Time |
|---|---|---:|
| 1 | AI review operating model | 60 min |
| 2 | Installation, privacy and scope | 60 min |
| 3 | Configuration as policy | 75 min |
| 4 | Triage and resolution | 75 min |
| 5 | Workflow and quality gates | 60 min |
| 6 | Measurement and governance | 45 min |
| Labs + assessment | Practice and capstone | 105 min |

<div className="checkpoint"><strong>Prerequisite:</strong> Complete the GitHub collaboration modules or demonstrate equivalent skill with branches, pull requests, reviews, checks, YAML, and basic CI.</div>
