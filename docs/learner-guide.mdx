# Learner & Accessibility Guide

## Before you start

Read the selected course guide, confirm the prerequisites, and create a private practice environment. Never use a production repository, live payment method, real customer data, or unreviewed automated change for a learning exercise.

## A productive study cycle

1. Read the outcome at the top of a module and complete its short diagnostic prompt.
2. Work through the explanation and examples; follow links when a feature or plan differs for your account.
3. Complete the checkpoint without looking back, then review the feedback.
4. Perform the lab in a sandbox and retain only the evidence named in the lab.
5. Redact secrets, personal data, customer data, tokens, and private URLs before submitting evidence.

## Accessibility and reasonable alternatives

The site supports keyboard navigation, responsive zoom, dark mode, semantic headings, text alternatives, and reduced-motion preferences. Code and commands are supplied as selectable text. Learners may:

- replace a screenshot with a structured text description or exported configuration;
- use a keyboard, screen reader, voice input, or other assistive technology;
- request extra time, rest breaks, an oral explanation, or an equivalent non-visual task;
- use a simulated repository/store when account permissions or paid features are unavailable.

An alternative must assess the same outcome and use the same rubric. Accessibility accommodations never reduce the competency threshold.

## Support and escalation

For content ambiguity, record the page title, the statement in question, expected behaviour, and observed behaviour. For safety or privacy concerns, stop the activity and contact the Academy support channel published in your learner portal. Vendor account, billing, and availability issues belong with the vendor support service.

## Academic integrity and AI

You may use documentation, assistive tools, and AI unless an assessment says otherwise. You remain responsible for verifying every submitted action and explanation. Cite external help, do not submit generated evidence you did not produce, and never disclose credentials or confidential code to an unapproved service.
