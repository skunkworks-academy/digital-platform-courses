# GitHub Foundations & Delivery

**SKW-GH-101 · Beginner to intermediate · 12 hours · Self-paced**

Learn GitHub as a delivery system, not merely a place to store files. You will create a governed repository, collaborate through issues and pull requests, automate quality checks, and produce a secure release.

## What you will be able to do

By completion, you can:

1. Explain Git, GitHub, repositories, commits, branches, remotes, and the working tree.
2. Create a repository with purposeful documentation, access, and contribution controls.
3. Use issues, branches, commits, pull requests, reviews, and conflict resolution in a traceable workflow.
4. Build and troubleshoot a GitHub Actions continuous-integration workflow.
5. Apply least privilege, secret hygiene, dependency controls, and repository security practices.
6. Plan and publish a versioned release with verifiable evidence.
