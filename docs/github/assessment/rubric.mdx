# GitHub Capstone Rubric

| Criterion | Weight | Meets standard | Critical? |
|---|---:|---|:---:|
| Repository purpose and governance | 10 | Purpose, contribution, security, ownership and access are coherent | No |
| Issue and acceptance design | 10 | Need is bounded, traceable and objectively testable | No |
| Git history and change quality | 15 | Focused branch/commits; correct implementation; explainable history | No |
| Pull request and human review | 15 | Risk/test/rollback evidence; substantive finding resolved | No |
| CI workflow | 15 | Reproducible, least privilege, useful failure diagnosis, final pass | Yes |
| Security controls | 15 | Secrets, identity, dependency, code and workflow risks addressed | Yes |
| Release and recovery | 10 | Version, notes, evidence and practical rollback are complete | No |
| Reflection and evidence integrity | 10 | Authentic, redacted, sufficient evidence and measurable improvement | Yes |

Score each criterion at 0%, 50%, 70%, 85%, or 100% of its weight: missing/unsafe, partial, meets, strong, exemplary. Pass at **70/100** and meet all critical criteria. Feedback must identify evidence, gap, and next action.
