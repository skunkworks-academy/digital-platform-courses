# Lab 2 — Accessible Storefront QA

**Time:** 60 minutes

Duplicate the theme. Configure home, collection, product, search, cart, contact and policy journeys with coherent navigation and brand hierarchy. On a product page, make price, selected variant, availability, purchase action, delivery and return information discoverable.

Test at 320 CSS pixels, 200% zoom, keyboard only, reduced-motion preference and at least one screen reader if available. Check focus, headings, labels, errors, contrast, media alternatives, unavailable variants and empty states. Measure a representative page with browser performance tooling and remove or justify one costly asset/app.

<div className="evidence"><strong>Evidence:</strong> theme version/backup, annotated journey, accessibility checklist with defects and fixes, mobile/zoom evidence, performance before/after, and final regression result.</div>
