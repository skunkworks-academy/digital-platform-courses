# Shopify Knowledge Check

Score one point each; **10/12** passes.

1. Why is contribution margin more useful than revenue alone?
2. Name two reasons not to share the store-owner login.
3. What qualities should a SKU have?
4. When is a smart collection rule unsafe?
5. Name four product details that reduce avoidable returns.
6. Why version/duplicate a theme before changes?
7. Name three accessibility tests beyond checking an automated score.
8. Does platform-calculated tax prove legal compliance?
9. What mode must be used for coursework payments?
10. Name three shipping test cases.
11. Why may two analytics tools report different conversion?
12. Name two experiment guardrails besides conversion.

## Answer key

1. It includes variable costs and shows whether sales fund operations. 2. Accountability, least privilege, credential security (any two). 3. Unique, stable, operationally readable, not based on volatile data. 4. When it relies on inconsistent/ungoverned fields or has not been tested. 5. Examples: material, dimensions/fit, compatibility, care, contents, limitations, accurate imagery. 6. Safe preview, comparison and rollback. 7. Keyboard/focus, zoom/reflow, screen reader, contrast, reduced motion, errors (any three). 8. No. 9. Test mode/test gateway. 10. Below/above threshold, unsupported destination, different weight/market, pickup, discount (any three). 11. Definitions, consent, attribution, time zone, filters and tracking differ. 12. Margin, refunds, speed, accessibility, complaints, support contact (any two).
