# Skunkworks Academy Digital Platform Courses

One Docusaurus catalog containing three independent self-paced courses:

- SKW-GH-101 — GitHub Foundations & Delivery
- SKW-CR-201 — CodeRabbit AI Code Review
- SKW-SH-101 — Shopify Store Operations

## Local validation

```bash
npm ci
npm run typecheck
npm run build
npm run serve
```

Publishing is configured for GitHub Pages on pushes to `main`. Enable **Settings → Pages → Build and deployment → GitHub Actions** in the repository.

These courses are designed for standards alignment. They are not representations of ISO certification or official vendor certification.
